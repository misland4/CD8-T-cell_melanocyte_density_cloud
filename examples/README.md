# Example datasets

## Supplied research data

`research_density.xlsx` is an unmodified copy of the supplied `Simulated dataset to demo the code.xlsx`. The dataset provider confirmed that its seven pairs are real research observations. Its original worksheet name, `Simulated dataset`, remains unchanged.

Column B contains CD8+ T-cell counts and column C contains melanocyte counts. Row 1 contains headers; rows 2–8 contain seven observations in one group. This workbook generates the main README preview.

Source SHA-256: `248baa3371a525ef44e21161619536eaa1adfc047cfafd1316dd6b8d48035b8a`.

## Earlier synthetic example

`synthetic_density.xlsx` contains 14 manually specified synthetic pairs created during initial repository preparation. It is not research data and is not the source of the current main README preview.

It demonstrates the legacy two-group layout: D/E rows 17–23 form the dark green group, and D/E rows 24–30 form the light green group. The labels describe colors only.
